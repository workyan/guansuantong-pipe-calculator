# 产品需求文档（PRD）

## 1. 文档信息

- 产品：`管算通-管道计算器`
- 版本：V1.0
- 平台：iPhone
- 语言：简体中文
- 商业模式：CN¥18 付费下载
- 数据模式：本地离线
- 目标最小系统：iOS 17 或更高版本

## 2. 产品目标

### 用户目标

- 在施工现场用最少输入完成常见管道几何和坡度计算。
- 看懂计算过程，能够用卷尺和现场尺寸复核结果。
- 保存并分享结果，减少口头传递和二次抄写错误。
- 在无网络、地下室、厂房或弱网环境正常使用。

### 业务目标

- 从 `管道计算器` 等高意图自然搜索词获得付费下载。
- 以一次买断、无广告、完全离线建立专业工具信任。
- 将首版控制在个人开发者可完成和可验证的范围内。

### 非目标

- 不取代工程师签字、施工图设计、审图或验收。
- 不提供管道承压安全结论。
- 不提供实时材料价格。
- 不做工程项目 ERP 或多人协作。

## 3. 信息架构

底部四个标签：

1. `计算`
2. `项目`
3. `参考`
4. `设置`

### 计算首页

## 4. 功能需求

### 4.1 单平面弯头偏移

用户输入：

- 目标偏移量。
- 弯头角度：22.5°、30°、45°、60°，支持自定义。
- 可选：两个弯头的中心至端面尺寸。

输出：

- 斜管中心线行程。
- 水平推进量。
- 若提供两个管件扣除量，显示净切管长度。
- 使用的三角函数和中间值。
- 方向示意图。

交互：

- 常用角度使用大按钮。
- 修改任意输入后即时更新。
- 结果支持复制、收藏和加入项目。

### 4.2 滚动偏移

用户输入：

- 水平偏移。
- 垂直偏移。
- 弯头角度。
- 可选：两端管件扣除量。

输出：

- 真实偏移量。
- 滚动角。
- 中心线行程。
- 扣除管件后的净切管长度。
- 图示显示水平、垂直和真实偏移的关系。

错误处理：

- 任一输入为负值时提示检查方向，计算采用绝对尺寸。
- 输入为零时允许退化为单平面偏移。
- 净切管长度小于零时明确警告“管件扣除量超过中心线行程”。

### 4.3 坡度与标高

支持四种模式：

1. 已知水平距离和坡度，求落差。
2. 已知水平距离和落差，求坡度。
3. 已知起点、终点标高和距离，求坡度。
4. 已知起点标高、坡度、总距离和测点间距，生成支架标高表。

坡度单位：

- 百分比 `%`
- 千分比 `‰`
- 毫米每米 `mm/m`
- 比值 `1:n`
- 角度 `°`

输出：

- 总落差。
- 坡度的全部等价表示。
- 流向或升降方向。
- 每个测点的距离和目标标高。

### 4.4 切管长度

支持：

- 已知两连接点中心距，分别扣除两端管件中心至端面尺寸。
- 常用管件扣除量收藏。
- 左右两端可以使用不同扣除量。
- 显示毛坯长度、总扣除量和净切管长度。

V1 不内置宣称完整或强制性的国标管件尺寸库。用户可：

- 手动输入厂家或现场确认的中心至端面尺寸。
- 将常用尺寸保存为个人模板。

原因：

- 不同标准、压力等级、系列和厂家尺寸可能不同。
- 避免因错误或过时规格造成现场损失。

### 4.5 管材重量

用户输入：

- 外径。
- 壁厚。
- 长度。
- 数量。
- 材料密度。
- 可选单价。

内置材料密度仅作为参考：

- 碳钢。
- 304 不锈钢。
- 316 不锈钢。
- 铝。
- 紫铜。
- PVC。
- 自定义。

输出：

- 内径。
- 截面积。
- 每米理论重量。
- 单根重量。
- 总长度。
- 总重量。
- 若输入单价，显示估算材料成本。

单位：

- 尺寸：mm、cm、m、in。
- 长度：mm、cm、m、ft。
- 重量：kg、t、lb。
- 单价：每 kg、每 t。

### 4.6 项目与历史

项目字段：

- 项目名称。
- 位置或区域。
- 备注。
- 创建和修改时间。
- 多条计算记录。

计算记录保存：

- 计算器类型。
- 原始输入。
- 单位。
- 结果和中间量。
- 用户备注。
- 创建时间。

能力：

- 重命名、复制、删除。
- 按日期或项目筛选。
- 将单条结果生成图片。
- 将一个项目生成文本摘要。

V1 不做账号和跨设备同步。

### 4.7 参考

包含：

- 坡度单位换算表。
- 常用弯头角度乘数表。
- 管道重量公式说明。
- 如何测量中心距和中心至端面尺寸。
- 计算结果复核清单。
- 安全与责任说明。

参考内容必须：

- 使用自编图示和文字。
- 不复制受版权保护的工程手册页面。
- 不冒充国家标准全文。
- 标注公式适用条件。

### 4.8 设置

- 默认长度单位。
- 默认重量单位。
- 默认坡度表示。
- 小数位：1、2、3。
- 四舍五入方式。
- 是否保存历史。
- 深色模式：跟随系统、浅色、深色。
- 隐私政策、支持和版本信息。

## 5. 核心用户流程

### 首次启动

1. 展示一句定位和免责声明。
2. 选择默认单位：公制为默认。
3. 进入计算首页。
4. 不要求注册，不弹出通知权限。

### 完成滚动偏移计算

1. 点击“滚动偏移”。
2. 输入水平偏移和垂直偏移。
3. 选择 45°。
4. 即时显示真实偏移、滚动角和中心线行程。
5. 可选填写两端扣除量。
6. 保存到项目或生成结果图片。

### 完成支架标高表

1. 点击“坡度标高”。
2. 选择“按间距生成测点”。
3. 输入起点标高、坡度、总距离和间距。
4. 查看每个测点标高。
5. 保存或复制表格文本。

## 6. UX 原则

- 单屏完成一个计算，不用多级表单。
- 结果数字优先于说明文字。
- 输入框直接显示单位，不让用户猜测。
- 切换单位时换算已有输入，不清空。
- 图示与输入字段使用相同颜色标识。
- 所有计算均可离线完成。
- 不使用假精度；默认保留 2 位，可由用户调整。
- 户外可读：高对比度、最小 44pt 触控区域。

## 7. 数据与隐私

V1：

- 所有项目、历史和设置仅保存在设备本地。
- 不接入登录、广告、分析或第三方追踪 SDK。
- 不收集姓名、位置、联系人或设备标识。
- 结果分享只在用户主动触发系统分享面板时发生。
- 删除 App 会删除本地数据；产品中需提供导出提醒。

App Privacy 预计申报：

```text
Data Not Collected
```

最终申报必须依据实际构建中包含的 SDK 和网络请求复核。

## 8. 错误、警告与免责声明

输入错误：

- 外径必须大于 0。
- 壁厚必须大于 0 且小于外径的一半。
- 长度和数量必须大于 0。
- 角度必须大于 0 且小于 90°。
- 比值分母必须大于 0。

风险提示：

- 理论重量会受材料牌号、制造公差、涂层和实际尺寸影响。
- 管件尺寸应以实际产品、厂家资料和项目标准为准。
- 计算结果仅用于估算、放样辅助和技术参考。
- 施工、切割、焊接和安装前必须由具备相应能力的人员复核。

## 9. V1.1/V2 路线

V1.1：

- PDF 项目报告。
- CSV 材料清单。
- 自定义结果卡片抬头。
- 更多管件模板。
- iPad 布局。

V2：

- 经专业复核的可选规格库。
- Apple Watch 坡度快捷计算。
- 仅在有充分关键词和用户反馈时增加流量、压降等水力计算。

明确不因“功能看起来丰富”而在 V1 加入流体设计。

## 10. 发布验收

- 每个公式至少有正常、边界和非法输入测试。
- 关键公式使用独立计算表或第二实现交叉验证。
- 单位切换往返误差在显示精度范围内。
- 100 条随机输入不得崩溃或产生 NaN/Infinity。
- 飞行模式下所有核心能力可用。
- 首次启动不请求与功能无关的权限。
- 支持动态字体，不截断关键结果。
- 深色模式下图示和输入保持可读。
