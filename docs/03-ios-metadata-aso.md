# iOS 商品元信息与 ASO

## 1. ASO 策略

首发集中争夺：

1. 管道计算器
2. 管道计算
3. 管工计算
4. 管道坡度
5. 管道重量
6. 弯头计算
7. 滚动偏移

不争夺：

- 通用计算器。
- 钢材行情和材料价格。
- 泵选型、流体力学、水力计算等 V1 未提供的功能。
- 竞品名称或品牌词。

## 2. 简体中文元信息

### App 名称

```text
管算通-管道计算器
```

覆盖：

- 品牌词：管算通。
- 最高优先级完整搜索词：管道计算器。

### 副标题

```text
弯头偏移·坡度标高·切管长度与重量
```

覆盖：

- 弯头偏移
- 坡度标高
- 切管长度
- 管道重量意图

### 关键词

```text
管工,焊工,安装,滚动偏移,落差,放样,钢管,给排水,消防,暖通,支架,算料,管径
```

说明：

- UTF-8 校验为 99 字节，不超过 100 字节；提交前用 App Store Connect 再次校验。
- 不重复名称中的“管道”“计算器”和副标题中的完整词。
- 通过名称、副标题和关键词组合覆盖“管工计算器”“钢管重量计算”“给排水坡度”等长尾。
- 不使用 `管道计算器Pro`、`算料宝`、`珠子云计算`等竞品名称。

### 推广文本

```text
为管工、焊工和安装现场设计：计算弯头与滚动偏移、排水坡度、支架标高、切管长度和管材理论重量。一次购买，无广告、无订阅，弱网和离线现场也能使用。
```

### 完整描述

```text
管算通是一款面向管道安装工、管工、焊工和现场技术人员的离线管道计算器。

它把弯头偏移、滚动偏移、坡度标高、切管长度和管材重量集中在一个清晰、可复核的工具中。无需注册，不依赖网络，也不会上传项目和现场数据。

【弯头偏移】

- 支持 22.5°、30°、45°、60°及自定义角度
- 根据偏移量计算中心线行程和水平推进量
- 可输入两端管件扣除量，得到净切管长度
- 显示计算公式、中间量和方向图示

【滚动偏移】

- 输入水平偏移和垂直偏移
- 自动计算真实偏移量和滚动角
- 计算斜管中心线行程
- 支持管件扣除和异常尺寸提醒

【坡度与标高】

- 根据距离和坡度计算总落差
- 根据距离和落差反算坡度
- 支持百分比、千分比、毫米每米、比值和角度
- 按固定间距生成支架或测点标高表
- 清楚显示流向、升降方向和等价坡度

【切管长度】

- 输入连接点中心距
- 分别扣除两端弯头或管件中心至端面尺寸
- 保存常用管件扣除量
- 显示毛坯长度、总扣除量和净切管长度

【管材重量】

- 输入外径、壁厚、长度和数量
- 计算内径、截面积、每米理论重量、单根重量和总重量
- 支持碳钢、不锈钢、铝、铜、PVC及自定义密度
- 支持公制和英制常用单位
- 可输入材料单价估算成本

【项目和分享】

- 将多条计算记录保存到同一项目
- 收藏常用计算器和输入模板
- 生成带输入、结果、单位和时间的结果卡片
- 通过系统分享面板发送给同事或保存到文件

【离线买断】

- 一次购买，无广告，无订阅
- 无需账号，不接入第三方追踪
- 核心计算完全离线
- 项目和历史仅保存在本机

重要说明：

本 App 提供现场估算、放样辅助和技术参考，不构成正式工程设计、施工方案、审图、验收或安全评估意见。理论重量会受材料、制造公差和实际尺寸影响；管件尺寸应以实际产品、厂家资料和项目标准为准。切割、焊接和安装前，请由具备相应能力的人员复核输入、单位和结果。
```

## 3. 截图方案

建议 7 张 iPhone 竖版截图：

1. `管道现场计算，一个工具就够`
   - 展示五类计算入口。
2. `弯头偏移，行程与切管长度立即得到`
   - 展示 45°偏移输入、简图和结果。
3. `水平加垂直，滚动偏移自动算`
   - 展示真实偏移和滚动角。
4. `坡度落差与支架标高，一次生成`
   - 展示测点表。
5. `中心距扣除管件，切管不再手算`
   - 展示两端不同扣除量。
6. `管径壁厚长度，理论重量快速汇总`
   - 展示钢管重量。
7. `一次买断·完全离线·无广告订阅`
   - 展示隐私和离线价值。

首图要求：

- 必须展示真实计算界面，而不是抽象海报。
- 露出 `管道计算器`定位。
- 不显示未完成的水力、压降或泵选型功能。

禁止文案：

- `100%准确`
- `保证施工安全`
- `符合所有国标`
- `替代工程师`
- `验收必过`

## 5. 上线后 ASO 迭代

每周记录：

- 搜索曝光量。
- 产品页浏览量。
- 付费下载量。
- 产品页转化率。
- 退款量。
- 核心关键词排名。
- 用户评论中出现的任务词。

迭代规则：

- `管道计算器`有曝光无购买：先调整首图和价值表达，不急于加功能。
- 偏移相关词排名好：强化弯头和滚动偏移截图。
- 坡度词带来下载：将支架标高表提前到第二张截图。
- 评论集中要求流量或压降：先验证搜索量和专业复核资源，再决定独立 App 或 V2。
- 不同时修改名称、副标题、关键词、截图和价格，避免无法判断原因。
