# 计算口径与验收样例

本文件用于产品、开发和测试统一口径，不替代专业工程标准。

## 1. 单位约定

- 内部长度统一换算为米或毫米后计算，禁止混用。
- 角度输入为度，进入三角函数前转换为弧度。
- 质量计算内部使用 kg。
- UI 显示精度与内部计算精度分离。
- 内部使用双精度浮点数；只在最终显示时四舍五入。

## 2. 单平面偏移

定义：

- `O`：垂直于原管线方向的目标偏移。
- `θ`：弯头转角，0° < θ < 90°。
- `T`：两个弯头中心之间的斜向行程。
- `A`：沿原管线方向的推进量。

公式：

```text
T = O / sin(θ)
A = O / tan(θ)
```

若两端中心至端面扣除量分别为 `e1`、`e2`：

```text
净切管长度 = T - e1 - e2
```

验收样例：

- O = 500 mm
- θ = 45°
- T ≈ 707.1068 mm
- A = 500 mm

若 e1 = 50 mm、e2 = 50 mm：

- 净切管长度 ≈ 607.1068 mm

## 3. 滚动偏移

定义：

- `H`：水平偏移。
- `V`：垂直偏移。
- `O`：真实偏移。
- `φ`：滚动角，以水平偏移轴为基准。
- `θ`：弯头转角。
- `T`：斜管中心线行程。

公式：

```text
O = sqrt(H² + V²)
φ = atan2(V, H)
T = O / sin(θ)
```

验收样例：

- H = 300 mm
- V = 400 mm
- θ = 45°
- O = 500 mm
- φ ≈ 53.1301°
- T ≈ 707.1068 mm

若两端扣除量各 50 mm：

- 净切管长度 ≈ 607.1068 mm

## 4. 坡度与落差

定义：

- `R`：水平距离。
- `D`：落差，有方向。
- `s`：坡度小数。

公式：

```text
s = D / R
D = R × s
百分比 = s × 100
千分比 = s × 1000
mm/m = s × 1000
比值 1:n 中，n = 1 / |s|
角度 = atan(s)
```

验收样例：

- R = 10 m
- 坡度 = 2%
- D = 0.2 m = 200 mm
- 千分比 = 20‰
- mm/m = 20
- 比值 = 1:50
- 角度 ≈ 1.1458°

## 5. 测点标高

定义：

- 起点标高 `E0`。
- 坡度小数 `s`。
- 测点距起点距离 `x`。
- 流向下降为负方向。

公式：

```text
E(x) = E0 - x × s
```

如果用户选择“上升”，改为：

```text
E(x) = E0 + x × s
```

验收样例：

- E0 = 100.000 m
- s = 2%
- 总距离 = 5 m
- 间距 = 1 m

下降方向测点：

| 距离 | 标高 |
|---:|---:|
| 0 m | 100.000 m |
| 1 m | 99.980 m |
| 2 m | 99.960 m |
| 3 m | 99.940 m |
| 4 m | 99.920 m |
| 5 m | 99.900 m |

## 6. 切管长度

定义：

- 两连接点中心距 `C`。
- 左端中心至端面扣除 `e1`。
- 右端中心至端面扣除 `e2`。

公式：

```text
净切管长度 = C - e1 - e2
```

验收样例：

- C = 1200 mm
- e1 = 75 mm
- e2 = 90 mm
- 净切管长度 = 1035 mm

产品不得假设不同标准、压力等级和厂家的管件扣除尺寸完全相同。

## 7. 圆管理论重量

定义：

- 外径 `D`。
- 壁厚 `t`。
- 内径 `d = D - 2t`。
- 长度 `L`。
- 数量 `N`。
- 密度 `ρ`。

截面积：

```text
A = π / 4 × (D² - d²)
```

单根质量：

```text
m = A × L × ρ
```

总质量：

```text
M = m × N
```

使用 SI 单位时：

- D、d、t、L 使用 m。
- A 使用 m²。
- ρ 使用 kg/m³。
- m、M 得到 kg。

验收样例：

- 碳钢参考密度 7850 kg/m³
- D = 60 mm = 0.06 m
- t = 3 mm = 0.003 m
- d = 54 mm = 0.054 m
- L = 6 m
- N = 1

结果：

- A ≈ 0.00053721 m²
- 每米理论重量 ≈ 4.2171 kg/m
- 单根理论重量 ≈ 25.3027 kg

## 8. 边界测试

必须拒绝或提示：

- 角度 ≤ 0°或 ≥ 90°。
- 外径 ≤ 0。
- 壁厚 ≤ 0。
- 壁厚 ≥ 外径 / 2。
- 长度 ≤ 0。
- 数量不是正数。
- 密度 ≤ 0。
- 坡度比值分母为 0。
- 管件扣除后净切管长度 ≤ 0。
- 输入超出合理数值范围导致结果溢出。

## 9. 专业复核要求

开发完成后：

1. 使用独立电子表格复核所有验收样例。
2. 由至少一名实际管道从业者确认“偏移、行程、推进、扣除、标高”等术语。
3. 用实际厂家管件数据测试自定义扣除模板。
4. 不将参考密度和管件尺寸描述为强制标准值。
5. 每次修改公式或单位换算时运行全部回归测试。
